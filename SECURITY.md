# Security

Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.

## Report a vulnerability

Email [hello@caifrazier.com](mailto:hello@caifrazier.com) with the subject line "Security vulnerability." Include the plugin name and version, WordPress and PHP versions, and enough detail to reproduce the issue.

The same contact and policy are published at [https://caifrazier.com/security/](https://caifrazier.com/security/).

## Scope

This policy covers the plugins published in this repository. It does not cover third-party services, client websites, or software Cai Frazier did not publish.

## What to expect

We review reports sent to that address. We do not offer a bug bounty. Please give us a reasonable window to address a report before public disclosure.
