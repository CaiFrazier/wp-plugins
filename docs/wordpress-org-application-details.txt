CF Media Optimizer 3.0.4
Additional details

Converts JPEG and PNG attachments to WebP, and to AVIF where the server supports it. Conversion runs on the site's server. The plugin adds picture markup with the original image as the fallback and keeps the original files intact.

WebP needs GD or Imagick with the appropriate encoder. Background conversion uses Action Scheduler when available, otherwise WP-Cron. The live-page verifier makes an HTTP request to the public URL an administrator chooses. There is no hosted conversion service or telemetry sent to me.

My local test server lacks an AVIF encoder, so two AVIF-specific tests were skipped. AVIF availability depends on the host.

Requires WordPress 6.2+ and PHP 8.1+. Licensed GPL-2.0-or-later; dependency license notices are included. Plugin Check 2.1.0 reported no errors or warnings.

CF Chunked Upload 1.2.2
Additional details

Uploads large files as smaller browser requests, then assembles them on the server. It works in the Media Library and through Tools > Import Large File. Each request still has to fit the host's limits.

Chunks stay on the site's server and are checked with SHA-256. Upload sessions belong to the user who started them. Quota and free-space checks limit storage use. Assembly and cleanup need a working WP-Cron setup or Action Scheduler.

Nginx users need the temporary-directory deny rule documented in the readme. Imported files remain after the plugin is removed. This version does not install plugin or theme ZIPs. It uses no external service and sends no telemetry.

CF QR Redirect 1.3.2
Additional details

Creates short URLs on the site's own domain and generates QR images in the browser. qrcode.js and JSZip are bundled with their licenses. WordPress capabilities control who can create or change codes and redirects.

Redirecting to external HTTP(S) destinations is part of the plugin's intended use. Destinations are saved by authorized users and validated. Visitors cannot pass in their own redirect destination.

The default mode adds UTM parameters and redirects without loading an analytics script. Optional intermediate-page mode loads Google's gtag.js and sends a qr_redirect event to the configured GA4 property. Google receives the request information and may use cookies. That page does not inherit the theme's consent manager. The readme explains the consent requirement and links to Google's terms and privacy policy.

Hit counts, destination-change records, and captured 404 data stay in WordPress, with retention limits described in the readme. No telemetry is sent to me.

Requires WordPress 6.2+ and PHP 8.1+. Licensed GPL-2.0-or-later; dependency license notices are included. Plugin Check 2.1.0 reported no errors or warnings.

Schema Override Manager 1.0.2
Additional details

Adds sitewide schema settings, post-type defaults, and per-post JSON-LD overrides. It works on its own and can also use Yoast SEO or Rank Math's schema hooks.

Settings stay in WordPress. The resulting JSON-LD is public on the website. The inspector requests the site's own post URL when an authorized user runs it. Schema.org URLs identify schema types; the plugin does not call a schema.org API. Optional diagnostic logs are stored under uploads.

Theme-output suppression is off by default. When enabled for a matching page, it buffers only wp_head. Saved schema is sanitized and has size and nesting limits. There is no required external service or telemetry.

Requires WordPress 6.2+ and PHP 8.1+. Licensed GPL-2.0-or-later; dependency license notices are included. Plugin Check 2.1.0 reported no errors or warnings.
